==========================
SciPy 2.0.0 Release Notes
==========================

.. note:: SciPy 2.0.0 is not released yet!

.. contents::

SciPy 2.0.0 is the culmination of X months of hard work. It contains
many new features, numerous bug-fixes, improved test coverage and better
documentation. There have been a number of deprecations and API changes
in this release, which are documented below. All users are encouraged to
upgrade to this release, as there are a large number of bug-fixes and
optimizations. Before upgrading, we recommend that users check that
their own code does not use deprecated SciPy functionality (to do so,
run your code with ``python -Wd`` and check for ``DeprecationWarning`` s).
Our development attention will now shift to bug-fix releases on the
1.18.x branch, and on adding new features on the main branch.

This release requires Python 3.12-3.15 and NumPy 2.0.0 or greater.

``scipy.optimize`` improvements
===============================

- `scipy.optimize.linprog` now accepts a ``callback`` for the HiGHS
  methods. While a simplex or interior-point solve is running, the
  original solution is not available, so ``x``, ``slack``, ``con`` and
  ``fun`` are NaN. The callback is called again with the returned result
  after the solver finishes. ``method='highs-ds'`` and
  ``method='highs-ipm'`` forward that solver's interrupt events, at most
  once per distinct iteration count HiGHS reports, and ``method='highs'``
  follows whichever solver runs. How often HiGHS raises those events is
  up to the solver. Interior-point events reported with iteration count
  ``-1`` (crossover and factorization) are not passed through. Returning
  ``True`` or raising ``StopIteration`` stops the solve with status 5.
  Status 4 is unchanged and still reports numerical difficulties. With
  ``integrality``, each new incumbent is reported with its objective and
  constraint residuals, and each distinct branch-and-bound node count
  HiGHS reports is reported as well. Interrupting a mixed-integer solve
  returns that incumbent when HiGHS has one.

*******************
Deprecated features
*******************

- `scipy.special.mathieu_cem` and `scipy.special.mathieu_sem` are deprecated
  and will be removed in SciPy 2.2.0. Use `scipy.special.mathieu_ce` and
  `scipy.special.mathieu_se` instead, converting the input from degrees to
  radians. For example, replace ``mathieu_cem(m, q, x)`` with
  ``mathieu_ce(m, q, np.deg2rad(x))``. Both APIs return derivatives per radian,
  so the returned derivative requires no conversion.
  The corresponding legacy functions in `scipy.special.cython_special`
  are also deprecated.
